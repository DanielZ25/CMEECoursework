# Week 1 – UNIX, Shell Scripting, Git, and LaTeX

This week introduces foundational computing skills essential for scientific workflows.

## Folder Structure


- `code/` — Shell scripts, LaTeX example, automation tools  
- `data/` — FASTA sequences, CSV files, text datasets  
- `results/` — Outputs generated by scripts (usually git-ignored)  
- `sandbox/` — Temporary testing space  

## Topics Covered

### UNIX & Shell Commands
- Navigation, file handling, pipes, redirection  
- Pattern matching (`grep`, `awk`), text processing (`tr`, `wc`, `tail`)  

### Shell Scripting
Scripts include:
- `boilerplate.sh` — template for scripts  
- `variables.sh` — special + user-defined variables  
- `tabtocsv.sh` / `csvtospace.sh` — format converters  
- `tiff2png.sh` — batch image conversion  
- `CountLines.sh`, `ConcatenateTwoFiles.sh` — command automation  

### Git Version Control
- Initialising repositories  
- Branching & merging  
- SSH connection to GitHub  
- `.gitignore` usage  

### LaTeX
- Scientific document structure  
- Bibliography (`FirstBiblio.bib`)  
- Automated compilation using `CompileLaTeX.sh`  

## Running Examples

```bash
cd week1/code
bash UnixPrac1.txt
bash tabtocsv.sh ../sandbox/test.txt
```
