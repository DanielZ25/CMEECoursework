# My CMEE Coursework Repository
> "I am going to try this new naughty thing on this experimental branch!"

This repository contains coursework and scripts developed during the CMEE Bootcamp at Imperial College London, Silwood Park.  

The CMEE Bootcamp focuses on UNIX, shell scripting, R, Python, etc.  


---

## This is the structure of CMEECoursework:

```
CMEECoursework/
│
├── week1/

│ ├── data/ # Input datasets used by scripts (Temperatures, FASTA)
│ ├── results/ # Outputs generated by code
│ ├── sandbox/ # Testing area
│ └── Week1/ # Test folder
│
├── week2/ 
| ├── code/ # Python scripts written during week 2 (has moved all the .py files here)
│ ├── data/ # Input datasets used by scripts (TestOaksData.csv, JustOaksData.csv, sequences.csv)
│ ├── results/ # Outputs generated by code (generated by align_seqs.py)
│ ├── sandbox/ # Testing area
|
├── week3/MyRCoursework/
│ ├── code/
│ │ ├── Florida.R # "Is Florida getting warmer?" question
│ │ ├── Florida_writeup.tex # LaTeX report answering “Is Florida getting warmer?”
│ │ ├── Florida_writeup.pdf # Compiled report (generated from .tex)
│ │ ├── TreeHeight.R # Calculates tree heights from angles and distances
│ │ ├── # Other  Weekly coding exercises
│ ├── data/ # CSV input files (e.g. temperature and tree data)
│ ├── results/ # Output figures (e.g. permutation histogram)
│ └── sandbox/ # Testing area
│
├── week4/
│ ├── code/
| | ├── PP_Regress.R # Linear regression question

```
