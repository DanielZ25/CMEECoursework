# Week 3 – R Programming Coursework

## Overview

Week 3 focuses on introducing fundamental and intermediate R programming concepts. This includes control flow, vectorisation, data input/output, simple numerical simulations, and regression-based ecological analysis. The exercises build a strong foundation for using R in ecological and evolutionary modelling.

All work for this week is stored inside the `MyRCoursework` directory, organised into `code/`, `data/`, and `results/`.

## Script Descriptions (code/)

### R Basics & Input/Output
- **basic_io.R** — Reading/writing CSV and RData files.
- **boilerplate.R** — Template for R scripts with author/date metadata.

### Control Flow & Conditions
- **control_flow.R** — Demonstrates if/else and loop structures.
- **R_conditionals.R** — Examples of conditional expressions.
- **break.R**, **next.R** — Use of `break` and `next` inside loops.
- **try.R** — Error handling using `try()`.

### Vectorisation & apply-family
- **Vectorize1.R**, **Vectorize2.R** — Rewrites loops into vectorised operations.
- **apply1.R**, **apply2.R** — Using `apply()`, `lapply()`, `sapply()` for cleaner code.
- **preallocated.R** — Highlights the importance of preallocating vectors for speed.
- **sample.R** — Random sampling examples.

### Statistical / Ecological Tasks
- **Girko.R** — Generates a Girko ellipse (random multivariate normal distribution visualisation).
- **Ricker.R** — Implements the Ricker population growth model.
- **TreeHeight.R** — Computes tree heights from trigonometric measurements.

### Main Applied Assignment
- **Florida.R** — Analyses Florida temperature data using regression and time-series methods.
- **Florida_writeup.tex / .pdf** — The written report submitted for this assignment.

## How to Run the Scripts

### Run any individual R script:
```bash
Rscript code/<scriptname>.R
```

Example:
```bash
Rscript code/Florida.R
```

### Load data interactively in R:
```r
data <- read.csv("data/florida_weather.csv")
```

### Compile the Florida report (.tex):
```bash
pdflatex code/Florida_writeup.tex
```
